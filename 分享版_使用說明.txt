X倍大盤動能計算 - 分享版使用說明

1. 開啟程式
直接雙擊「X倍大盤動能計算.exe」即可使用，不需要安裝 Python。

2. 資料來源與 Alpha Key
主要資料來源為 Yahoo Finance，不需要 API Key。
Alpha Vantage API Key 為選填：輸入後會在背景與 Yahoo 月資料交叉比對；只有 Yahoo 與本地快取都缺少本期必要月份時，才會嘗試以 Alpha 作為備援來源。
Alpha Key 不會寫入本機紀錄。Alpha 免費方案可能暫時限流；此時會保留可用快取並在檢查項目提示，稍候再按一次即可重試。

3. 正式計算
正式計算只使用已完成月份的月 K，正常完成後會更新 signals.csv 正式歷史紀錄。
正式週期依 signals.csv 最後一筆正式紀錄推算下一期。下一個基準月尚未結束時，會顯示黃色「尚未到正式計算時間，等待 X 月完成」；此時不抓價、不計算、不寫入紀錄。
基準月結束後的下一個日曆月第一天起即可按正式計算；產生的正式訊號日期會使用該月第一個美股交易日。
若 Yahoo 暫時無法取價，但本地快取已有本期完成月資料，程式會使用快取繼續計算。若快取不足且已輸入 Alpha Key，程式會再嘗試 Alpha 備援。
若 Yahoo、可用快取與 Alpha 都無法提供本期所需價格，程式不會拿舊月份回算，會顯示紅色「價格抓價異常，無法判斷動能」，不進行公式計算，也不寫入 signals.csv。

4. 月底預估
月底預估以本月目前價格暫代月底月 K，預估下一個執行月的標的與是否換倉，不會寫入正式紀錄。
因為需要本月價格，若 Yahoo、快取與 Alpha 都沒有本月資料，月底預估會停止計算並顯示紅色「抓價與備援」。

5. 快取與紀錄
資料儲存在 two_x_market_records 資料夾；請讓它與 EXE 保持在同一個資料夾。
第一次正式計算或月底預估會抓取價格並建立本地快取。五分鐘內再次操作通常會優先使用本地快取，避免重複線上取價。
離線時每個線上來源會快速逾時；若沒有可用快取或 Alpha 備援，程式會顯示紅色失敗提醒，而不會長時間卡住。

6. 檢查項目與異常
綠色表示正常、黃色表示提示或未執行、紅色表示需要注意的異常。
Alpha 比對欄位顯示「正常」代表差異在可接受範圍；顯示「差異」或「缺資料」時，請人工核對 Yahoo 與 Alpha 的月份價格。

7. 注意
本工具是投資輔助計算工具，不是投資建議。
正式計算採完成月 K；月底預估僅供提前觀察，請自行判斷使用。
